# ProcureX React Prototype v2

A richer, presentation-ready, **non-working** UI/UX prototype for the ProcureX startup-friendly public procurement concept.

## Includes
- React + Vite
- Responsive dashboard
- Interactive sidebar/navigation
- Challenge Studio with search/filter
- Startup discovery cards and simulated matching
- Expert evaluation dashboard
- Pilot management with milestones/KPIs
- Procurement readiness workflow
- Analytics dashboard with CSS charts
- Modals, toast notifications, simulated actions
- Demo Mode indicator
- Light/dark theme toggle

## Run
```bash
npm install
npm run dev
```

This project intentionally has no backend, database, authentication, payment system, real AI model, or real government API integration. All data is static/demo data.
